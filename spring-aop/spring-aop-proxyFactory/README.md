### 2. Description

The `ProxyFactory` class is a key part of Spring AOP. It creates proxy objects at runtime and weaves aspect logic into the method calls of the target object. By setting the target object, interfaces, advice, and other properties, `ProxyFactory` gives an easy way to create proxy objects and use aspect-oriented programming.

### 3. Main Features

1. **Create proxy objects**

   + Creates proxy objects dynamically. A proxy object stands for the target object and can run extra logic before and after method calls.

2. **Weave in aspect logic**

   + By adding advice (Advice), `ProxyFactory` can weave aspect logic into the method calls of the proxy object, to handle cross-cutting concerns.

3. **Support interface proxies and class proxies**

   + Supports the interface-based JDK dynamic proxy and the class-based CGLIB proxy. You can choose the proxy type you need.

4. **Flexible configuration options**

   + Has many configuration options, such as the target object, the interfaces, the advice, and the proxy type. You can configure it flexibly for your needs.

5. **Simplify AOP configuration**

   + Makes AOP configuration simpler. With a few simple API calls, you can create the proxy object and weave in the aspect logic. This lowers the complexity of AOP configuration.

### 5. Best Practices

This example uses the `ProxyFactory` class to create a proxy object and applies a before advice (MethodBeforeAdvice) to the method calls of the target object. First, it creates a proxy factory with `ProxyFactory` and sets the target object to an instance of the `MyService` class. Then it adds the before advice `MyMethodBeforeAdvice` to the proxy factory. Next, it calls the `getProxy()` method to get the proxy object and stores it in a variable of type `Object`. Finally, it prints the class name of the proxy object.

```java
public class ProxyFactoryDemo {

    public static void main(String[] args) {
        // Create the proxy factory and the target object
        ProxyFactory proxyFactory = new ProxyFactory(new MyService());
        // Create the advice
        proxyFactory.addAdvice(new MyMethodBeforeAdvice());
        // Get the proxy object
        Object proxy = proxyFactory.getProxy();
        // Call the method of the proxy object
        System.out.println("proxy = " + proxy.getClass());
    }
}
```

This class can serve as a target object. The proxy factory creates a proxy object for it, and extra logic is applied before and after its method calls. This is how aspect-oriented programming works.

```java

}
```

In the run result, the proxy object is generated by the Spring CGLIB dynamic proxy. It is an enhanced version of the `MyService` class.

### 6. Source Code Analysis

**Initialization phase**

In the `org.springframework.aop.framework.ProxyCreatorSupport#ProxyCreatorSupport()` method, the `ProxyCreatorSupport` class is the parent class of `ProxyFactory`. So when `ProxyFactory` is initialized, `ProxyCreatorSupport` is initialized too, so its features can be used when the proxy object is created. In the constructor, it sets the `aopProxyFactory` field to a `DefaultAopProxyFactory` object, which is used later to create AOP proxy objects.

```java
/**
 * Create a new ProxyCreatorSupport instance.
 */
public ProxyCreatorSupport() {
    this.aopProxyFactory = new DefaultAopProxyFactory();
}
```

In the `org.springframework.aop.framework.ProxyFactory#ProxyFactory(java.lang.Object)` constructor, the constructor takes a target object and sets it as the object to be proxied. Then it calls `ClassUtils.getAllInterfaces(target)` to get all the interfaces the target object implements, and sets them as the interfaces the proxy factory should proxy.

```java
/**
 * Create a new ProxyFactory.
 * <p>Will proxy all interfaces that the given target implements.
 * @param target the target object to be proxied
 */
public ProxyFactory(Object target) {
    setTarget(target);
    setInterfaces(ClassUtils.getAllInterfaces(target));
}

```

The `org.springframework.aop.framework.AdvisedSupport#setTarget` method takes an object and sets it as the target object of the proxy factory. Inside, it wraps the target object in a `SingletonTargetSource`, to make sure the same target object instance is returned every time the proxy is obtained.

```java
/**
 * Set the given object as the target.
 * Will create a SingletonTargetSource for the object.
 * @see #setTargetSource
 * @see org.springframework.aop.target.SingletonTargetSource
 */
public void setTarget(Object target) {
    setTargetSource(new SingletonTargetSource(target));
}
```

The `org.springframework.aop.framework.AdvisedSupport#setInterfaces` method sets the interfaces to be proxied. It takes a varargs parameter `interfaces`, the list of interfaces to proxy. Inside the method, it first uses `Assert.notNull(interfaces, "Interfaces must not be null")` to make sure the given interface array is not null. Then it clears the interface list already set in the current `ProxyFactory` object, loops over the given interface array, and calls the `addInterface(ifc)` method to add each interface to the list. This makes sure only the given interfaces are proxied when the proxy object is created.

```java
/**
 * Set the interfaces to be proxied.
 */
public void setInterfaces(Class<?>... interfaces) {
    Assert.notNull(interfaces, "Interfaces must not be null");
    this.interfaces.clear();
    for (Class<?> ifc : interfaces) {
        addInterface(ifc);
    }
}
```

**Proxy creation phase**

The `org.springframework.aop.framework.ProxyFactory#getProxy()` method creates a new proxy object from the settings in the factory. You can call this method repeatedly. The effect differs depending on the interfaces and interceptors that were added or removed. The method uses the default class loader, usually the thread context class loader (if a proxy needs to be created). Finally it returns the created proxy object.

[AopProxy Source Analysis](../spring-aop-aopProxy/README.md)

```java
/**
 * Create a new proxy object from the settings in this factory.
 * <p>Can be called repeatedly. The effect differs if interfaces have been added or removed. Interceptors can be added and removed.
 * <p>Uses the default class loader: usually the thread context class loader (if a proxy needs to be created).
 * @return the proxy object
 */
public Object getProxy() {
    return createAopProxy().getProxy();
}
```

The `org.springframework.aop.framework.ProxyCreatorSupport#createAopProxy` method first checks the `active` flag. If the current `ProxyFactory` object is not active, it calls the `activate()` method to activate it. Then it calls `getAopProxyFactory().createAopProxy(this)` to get the AOP proxy factory and creates the AOP proxy with the current `ProxyFactory` object as the argument. Finally it returns the created AOP proxy object.

[AopProxyFactory Source Analysis](../spring-aop-aopProxyFactory/README.md)

```java
/**
 * Subclasses should call this method to get a new AOP proxy. They should not create an AOP proxy with {@code this} as the argument.
 */
protected final synchronized AopProxy createAopProxy() {
    if (!this.active) {
        activate();
    }
    return getAopProxyFactory().createAopProxy(this);
}

```

The `org.springframework.aop.framework.ProxyCreatorSupport#getAopProxyFactory`
method returns the AOP proxy factory (AopProxyFactory) used by this proxy configuration. In the `ProxyCreatorSupport()` constructor, the `aopProxyFactory`
object is initialized to an instance of `DefaultAopProxyFactory`. So when the `getAopProxyFactory()` method is called, it returns a `DefaultAopProxyFactory`
object, which is used to create AOP proxy objects.

```java
/**
 * Return the AopProxyFactory used by this proxy configuration.
 */
public AopProxyFactory getAopProxyFactory() {
    return this.aopProxyFactory;
}
```
